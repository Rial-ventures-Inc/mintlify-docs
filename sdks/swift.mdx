Coming soon. The Swift SDK will bring native iOS capture, backed by App Attest and the Secure Enclave for hardware attestation and LiDAR depth as an additional on-device signal. It's being built against the same capture-flow contract as the Kotlin SDK — the same states, the same server-driven template steps — so a template that renders correctly on Android renders the same way on iOS.

The [REST API](/quickstart) works from any backend today, so you can integrate server-side while the native SDK is in development.
