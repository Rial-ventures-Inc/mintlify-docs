Coming soon. The React Native module will bridge over the native Kotlin and Swift SDKs rather than reimplement capture in JS — the camera, device attestation, and offline queue stay native, with a thin JS API on top so a cross-platform app gets the same capture guarantees as a fully native one.

The [REST API](/quickstart) works from any backend today, so you can integrate server-side while the native bridge is in development.
